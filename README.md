# Boot resources

Versioned boot support resources. Release assets are pinned by file size and
SHA-256; consumers should verify both before use. A new payload requires a new
release tag rather than replacing the contents of an existing release.

`ASSETS.json` records each file's verified upstream commit and path.
`SHA256SUMS.txt` contains checksums for the binary assets.
